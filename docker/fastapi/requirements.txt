# Backend (FastAPI gateway) — minimal dependencies
# ─────────────────────────────────────────────────────────────────────────────
# After the v0.25.57 AI overhaul, the backend only acts as a thin gateway
# that proxies AI requests to the standalone ``ai-service``. The heavy ML
# / AI libraries (litellm, sentence-transformers, langgraph, dashscope)
# live in ``requirements-ai.txt`` and are installed ONLY in the ai-service
# image. By default (``AI_SERVICE_EMBEDDED=false``) the backend never
# touches them at runtime, so we keep the gateway image small and fast.
#
# If you ever flip ``AI_SERVICE_EMBEDDED=true`` to run AI in-process again,
# install ``requirements-ai.txt`` on top of this file.
