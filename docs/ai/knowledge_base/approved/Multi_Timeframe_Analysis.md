# Multi-Timeframe Analysis

## Top-Down Analysis Approach

1. **Higher Timeframe (HTF)** — Determine the primary trend
   - Weekly chart → monthly trend
   - Daily chart → key support/resistance levels
   - 4H chart → medium-term structure
2. **Intermediate Timeframe (ITF)** — Identify the secondary move
3. **Lower Timeframe (LTF)** — Pinpoint entry/exit timing

## Timeframe Alignment Signals

- **All aligned** (HTF up, ITF up, LTF up) → Strong trend, hold or add
- **HTF up, ITF down, LTF up** → Pullback in uptrend, look for LTF buy signals
- **HTF down, ITF up, LTF down** → Bounce in downtrend, look for shorts
- **All conflicting** → Stay out, no clear edge

## Confluency Scoring

- Assign +1 for each timeframe showing same direction
- Score of +3 → high confidence
- Score of +2 → moderate confidence, wait for confirmation
- Score ≤1 → avoid trading, unclear direction

## Common Multi-TF Setups

- **Trend continuation:** HTF trend direction + ITF pullback completion + LTF reversal pattern
- **Breakout trading:** HTF resistance identified → LTF breakout with volume confirmation
- **Reversal trading:** HTF at support/resistance + ITF divergence + LTF candlestick pattern
