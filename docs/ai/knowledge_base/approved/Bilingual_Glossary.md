# Bilingual Crypto and Trading Glossary (English/Vietnamese)

> **Document Type**: Reference Glossary
> **Audience**: AI Assistant, End Users (Vietnamese-speaking)
> **Version**: 0.27.0+
> **Purpose**: Complete bilingual reference for crypto and trading terminology. The AI assistant uses this for consistent Vietnamese terminology in bilingual responses.

---

## How to Use

Terms are listed alphabetically by English name. Each entry includes: **Term (English)** → **Vietnamese translation** → **Short English definition**.

For more detailed definitions of specific terms, see: `LMView_Glossary.md`, `Technical_Analysis.md`, `Market_Microstructure.md`, or `Derivatives_and_Leverage.md`.
