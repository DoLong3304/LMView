# DeFi Analysis

## TVL (Total Value Locked) Trends
- Rising TVL → capital inflow, protocol health
- Falling TVL → capital exit, declining usage
- Dominance rankings show sector rotation (DEXs, lending, staking)

## Yield Farming Risks
- **Smart contract risk** — audited vs unaudited protocols
- **Impermanent loss (IL)** — price divergence between paired assets
    - Formula: `IL = 2*sqrt(price_ratio)/(1+price_ratio) - 1`
    - 2x divergence → ~5.7% IL, 3x → ~13.4%, 5x → ~25.5%
- **Impermanent loss** can offset yield gains; prioritize stable pairs or high yields
- **Rug pull risk** — new/low-liquidity protocols, anonymous teams

## Protocol Metrics (Uniswap, Aave)

### Uniswap
- Volume / TVL ratio → capital efficiency
- Fee generation → protocol sustainability
- Liquidity concentration (v3) ranges

### Aave
- Utilization rate → borrowing demand
- Reserve factor → protocol revenue
- Liquidation threshold → safety margins

## DEX vs CEX Volume
- DEX volume share rising → DeFi adoption
- DEX volume / CEX volume ratio → market structure trend
- Perpetual DEX growth → derivatives decentralization
