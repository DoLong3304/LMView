## How to Use

This glossary provides English terms with Vietnamese translations and English descriptions. The AI assistant uses this for bilingual responses. Terms are alphabetized by English name.

For quick lookup, use browser search (Ctrl+F) on term names.

## Glossary

| Term (EN) | Vietnamese (VI) | Description |
|-----------|-----------------|-------------|
| **A** | | |
| Altcoin | Altcoin | Any cryptocurrency other than Bitcoin. Examples: Ethereum, Solana, Cardano. |
| Anchor Point | Điểm neo | A fixed reference point on a chart used for drawing tools or pattern recognition. |
| API (Application Programming Interface) | API (Giao diện lập trình ứng dụng) | Set of endpoints that allow software systems to communicate with LMView backend. |
| ATR (Average True Range) | ATR (Khoảng giá trung bình thực) | Volatility indicator measuring average price range; used for stop placement and position sizing. |
| Ask Price | Giá hỏi (Ask) | Lowest price a seller is willing to accept. Opposite of bid. |
| Asset | Tài sản | Financial instrument; in LMView typically cryptocurrency trading pair like BTCUSDT. |
| **B** | | |
| Bear Market | Thị trường giảm | Market condition where prices are falling (typically -20% from recent high). |
| Bid-Ask Spread | Chênh lệch giá (Spread) | Difference between best bid and best ask; indicates liquidity. |
| Bollinger Bands (BB) | Dải Bollinger | Volatility indicator: SMA ± standard deviation bands. Used to identify overbought/oversold and squeezes. |
| Breakout | Phá vỡ | Price movement through a defined support or resistance level, often with increased volume. |
| Bull Market | Thị trường tăng | Market condition where prices are rising (typically +20% from recent low). |
| **C** | | |
| Candlestick | Nến (cây nến) | Price chart representation showing OHLC (Open, High, Low, Close) as a body with wicks. |
| Candlestick Pattern | Mẫu hình nến | Recurring candlestick formations that predict price movements (e.g., doji, hammer, engulfing). |
| Centralized Exchange (CEX) | Sàn giao dịch tập trung (CEX) | Cryptocurrency exchange operated by a central company (e.g., Binance, Coinbase). |
| Coin | Đồng xu / Coin | Cryptocurrency token with its own blockchain (e.g., Bitcoin, Ethereum). |
| Consolidation | Tích lũy | Price movement within a tight range; low volatility period before breakout. |
| Correction | Điều chỉnh | Short-term price decline against the prevailing trend (typically 10-20%). |
| Cryptocurrency | Tiền mã hóa | Digital currency secured by cryptography, operating on blockchain networks. |
| **D** | | |
| DEX (Decentralized Exchange) | Sàn giao dịch phi tập trung (DEX) | Peer-to-peer cryptocurrency exchange without central intermediary (e.g., Uniswap). |
| Dead Cat Bounce | Bounce mèo chết | Temporary recovery during a downtrend; false hope before further decline. |
| Depth | Độ sâu (order book) | Order book showing bid and ask orders at various price levels. |
| Dip | Điều chỉnh / Mua đáy | Temporary price drop; opportunity to buy at lower price. |
| Drawdown | Sụt giảm | Peak-to-trough decline in value, expressed as percentage. |
| Dumping | Bán tháo | Large-scale selling causing rapid price decline. |
| **E** | | |
| EMA (Exponential Moving Average) | EMA (Trung bình động mũ) | Moving average giving more weight to recent prices; faster than SMA. |
| Exchange | Sàn giao dịch | Platform for buying/selling cryptocurrencies (e.g., Binance, OKX). |
| **F** | | |
| Fiat | Tiền pháp định | Government-issued currency (USD, VND, EUR). |
| Fibonacci Retracement | Kéo hồi Fibonacci | Tool using ratios (23.6%, 38.2%, 50%, 61.8%) to identify potential support/resistance after a move. |
| FOMO (Fear Of Missing Out) | FOMO (Sợ bỏ lỡ) | Emotional drive to buy an asset fearing missed gains; often leads to buying at peaks. |
| FUD (Fear, Uncertainty, Doubt) | FOMO (Sợ hãi, Không chắc chắn, Hoài nghi) | Negative sentiment spread to cause selling; market manipulation tactic. |
| Fundamental Analysis | Phân tích cơ bản | Evaluating asset value based on underlying factors (technology, adoption, revenue, etc.). |
| **G** | | |
| Gas | Phí gas | Fee paid to execute transactions on blockchain (Ethereum). |
| Gann Tools | Công cụ Gann | Drawing tools based on W.D. Gann's geometric analysis (angles, fans, squares). |
| Golden Cross | Chữ thập vàng | When short-term MA crosses above long-term MA (e.g., SMA 50 crossing SMA 200); bullish signal. |
| Green Candle | Nến xanh | Candle where close > open (price increased during period). |
| **H** | | |
| Hammer | Búa | Bullish reversal candlestick with small body and long lower wick; appears at bottoms. |
| HODL | HODL (giữ) | Misspelling of "hold"; means buy and hold long-term regardless of volatility. |
| Hot Wallet | Ví nóng | Cryptocurrency wallet connected to internet; convenient but less secure. |
| **I** | | |
| Ichimoku Cloud | Đám mây Ichimoku | Comprehensive Japanese indicator showing trend, support/resistance, and momentum via cloud. |
| Indicator | Chỉ báo | Mathematical calculation from price/volume displayed on chart (e.g., RSI, MACD). |
| Inflation | Lạm phát | General increase in prices; fiat devaluation drives crypto adoption. |
| **K** | | |
| K-line | Đường K (Nến) | Same as candlestick; displays OHLC data. |
| **L** | | |
| Liquidation | Thanh lý | Closing of leveraged position when price moves against it and margin is exhausted. |
| Liquidity | Tính thanh khoản | Ease of buying/selling without affecting price; high liquidity = tight spreads. |
| Long Position | Vị thế MUA (Long) | Bet that price will rise; buy asset hoping to sell higher later. |
| Low | Đáy | The lowest price reached in a period. |
| **M** | | |
| MACD (Moving Average Convergence Divergence) | MACD (Hội tụ phân kỳ trung bình động) | Momentum indicator showing relationship between two EMAs; includes histogram. |
| Market Cap (Market Capitalization) | Vốn hóa thị trường | Total value = price × circulating supply. Used to rank cryptocurrencies. |
| Market Order | Lệnh thị trường | Order to buy/sell immediately at best available price. |
| Margin | Ký quỹ | Collateral required for leveraged trading. |
| Memecoin | Memecoin | Cryptocurrency based on internet memes, often highly speculative (e.g., Dogecoin, Shiba Inu). |
| Miner | Thợ khai thác | Entity that validates blockchain transactions and earns block rewards (Proof-of-Work). |
| Mining | Khai thác | Process of validating transactions and creating new blocks on blockchain. |
| Moon | Moon (lên trời) | Slang for extreme price increase; "to the moon!" |
| Moving Average (MA) | Trung bình động | Smooths price data by averaging over period; types include SMA, EMA. |
| **O** | |
| OHLC | OHLC (Mở, Cao, Thấp, Đóng) | Open, High, Low, Close prices for a period; standard candlestick data. |
| Order Book | Sổ lệnh (Order Book) | Real-time list of buy and sell orders organized by price. |
| Overbought | Quá mua | Condition where price has risen too much, likely to correct downward (e.g., RSI > 70). |
| Oversold | Quá bán | Condition where price has fallen too much, likely to rebound upward (e.g., RSI < 30). |
| **P** | |
| P2P (Peer-to-Peer) | P2P (Ngang hàng) | Direct transactions between parties without intermediary. |
| Pair | Cặp giao dịch | Two assets traded against each other (e.g., BTC/USDT). |
| Pattern | Mẫu hình | Recognizable price formation indicating future movement (chart patterns, candlestick patterns). |
| Pendulum | Con lắc | Analogy for market swings between extremes (bullish/bearish). |
| Perpetual Contract | Hợp đồng vĩnh cửu | Derivative with no expiry date; popular for crypto leverage trading. |
| Pivot | Điểm xoay | Significant price level where trend may reverse; calculated from previous period's HLC. |
| Pump and Dump | Bơm và bán | Manipulation: inflate price with false hype, then sell at peak. |
| **R** | |
| Red Candle | Nến đỏ | Candle where close < open (price decreased). |
| Resistance | Kháng cự | Price level where selling pressure emerges, preventing further rise. |
| Return on Investment (ROI) | Lợi tức đầu tư (ROI) | Profit percentage relative to investment cost. |
| Reversal | Đảo chiều | Change in trend direction (uptrend → downtrend or vice versa). |
| RSI (Relative Strength Index) | RSI (Chỉ số sức mua bán) | Momentum oscillator (0-100); overbought >70, oversold <30. |
| **S** | |
| Satoshi | Satoshi | Smallest Bitcoin unit (0.00000001 BTC); also "sats". |
| Scalping | Giao dịch lướt | Trading style aiming for small profits on tiny price moves; holds seconds to minutes. |
| Sell | Bán | Dispose of asset; exit long position. |
| Shilling | Quảng bá | Promoting a cryptocurrency aggressively (often paid shills). |
| Short Position | Vị thế BÁN (Short) | Bet that price will fall; borrow and sell now, buy back later cheaper. |
| Signal | Tín hiệu | Indicator or pattern suggesting trading action (buy/sell). |
| Spot Trading | Giao dịch spot | Immediate settlement (buy/save actual asset); opposite of derivatives. |
| Spread | Chênh lệch giá | Difference between bid and ask; also difference between related prices (futures vs spot). |
| SMA (Simple Moving Average) | SMA (Trung bình động đơn giản) | Average of closing prices over N periods; basic trend indicator. |
| Stablecoin | Stablecoin | Cryptocurrency pegged to stable asset (USD, VND); e.g., USDT, USDC. |
| Staking | Staking (Đặt cọc) | Locking crypto to support blockchain operation and earn rewards (Proof-of-Stake). |
| Stop Loss (SL) | Dừng lỗ (Stop Loss) | Automatic sell order to limit losses at predetermined price. |
| Support | Hỗ trợ | Price level where buying pressure emerges, preventing further decline. |
| Supertrend | Supertrend | Trend-following indicator showing dynamic support/resistance lines. |
| **T** | |
| Take Profit (TP) | Chốt lời (Take Profit) | Automatic sell order to lock in gains at predetermined price. |
| Technical Analysis (TA) | Phân tích kỹ thuật (TA) | Study of price charts and indicators to predict future movements. |
| Tick | Tick | Single price update; minimum price movement. |
| Timeframe | Khung thời gian | Chart period per candle (1m, 5m, 1h, 1d, 1w). |
| Token | Token | Digital asset on existing blockchain (e.g., ERC-20 on Ethereum). |
| Toro | TORO (Đồng hồ) | Platform where users copy trades of experienced traders. |
| Trend | Xu hướng | General price direction: uptrend (higher highs/lows), downtrend (lower highs/lows), sideways. |
| **V** | |
| VWAP (Volume Weighted Average Price) | VWAP (Giá trung bình theo khối lượng) | Intraday benchmark; average price weighted by traded volume. |
| Volatility | Biến động | Measure of price variation over time; high volatility = large price swings. |
| Volume | Khối lượng | Number of units traded in a period; confirms strength of moves. |
| **W** | |
| Wallet | Ví | Software/hardware device storing cryptocurrency private keys. |
| Whale | Cá voi | Large holder with enough capital to move markets single-handedly. |
| Whipsaw | Dao động | Price moving sharply up then down (or vice versa) causing stop losses to trigger. |
| Wick | Bóng (nến) | Thin line on candlestick showing high-low range (aka shadow). |

## Notes for AI Assistant

1. **Translation Direction**: When responding in Vietnamese, use the Vietnamese column. When responding in English, use the English term.
2. **Description Usage**: The English description explains the term's meaning in trading context; use it to craft accurate explanations.
3. **LMView Terms**: Platform-specific terms (Drawing Tool, Data-Space, Function Calling) refer to LMView's unique features; explain accordingly.
4. **No User-Facing Jargon**: When talking to end users, explain terms simply. Use analogies when helpful.
5. **Tone**: Neutral, educational; avoid hype ("to the moon") in formal explanations.
